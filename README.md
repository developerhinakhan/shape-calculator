# Shape Calculator 🧮

A simple Python project demonstrating Object-Oriented Programming concepts such as **Polymorphism, Method Overriding, and Duck Typing**.

## 📌 Project Description

This project calculates the area of different shapes using a common interface.

Shapes implemented:

* Circle
* Rectangle

Each shape implements its own `area()` method.

## 🧠 Concepts Used

* Python OOP
* Polymorphism
* Method Overriding
* Duck Typing
